# Introduction to Equations — Solutions

> [Tutorial](README.md) · [Exercises](exercises.md)

Every solution below names the operation applied to both sides and checks the answer in the original equation. The check is part of the solution, not an optional extra.

## Beginner

**1.** $x+9=14$. Subtract $9$ from both sides (addition property with $c=-9$):
$$x+9-9=14-9\implies x=5.$$
Check: $5+9=14$. Solution set $\{5\}$.

**2.** $y-7=-2$. Add $7$ to both sides:
$$y-7+7=-2+7\implies y=5.$$
Check: $5-7=-2$.

**3.** $6m=54$. Divide both sides by $6$:
$$\dfrac{6m}{6}=\dfrac{54}{6}\implies m=9.$$
Check: $6\cdot9=54$.

**4.** $\frac{t}{4}=12$. Multiply both sides by $4$:
$$4\cdot\dfrac{t}{4}=4\cdot12\implies t=48.$$
Check: $48/4=12$.

**5.** $-3x=21$. Divide both sides by $-3$:
$$\dfrac{-3x}{-3}=\dfrac{21}{-3}\implies x=-7.$$
Check: $-3(-7)=21$.

**6.** $\frac{x}{5}=-2$. Multiply both sides by $5$:
$$x=-10.$$
Check: $-10/5=-2$.

**7.** $8+x=3$. Subtract $8$ from both sides:
$$x=3-8=-5.$$
Check: $8+(-5)=3$.

**8.** $2x=1$. Divide by $2$:
$$x=\dfrac12.$$
Check: $2\cdot\frac12=1$. The solution is a fraction; there is no requirement that it be an integer.

**9.** $3x+4=19$. Subtract $4$:
$$3x=15.$$
Divide by $3$:
$$x=5.$$
Check: $3(5)+4=19$.

**10.** $5x-7=18$. Add $7$:
$$5x=25.$$
Divide by $5$:
$$x=5.$$
Check: $5(5)-7=18$.

**11.** Substitute $x=3$ into the left side:
$$4(3)-5=12-5=7.$$
The right side is $7$, so the equation is true at $x=3$. Yes, $x=3$ is a solution.

## Intermediate

**12.** $2x+9=3$. Subtract $9$:
$$2x=-6.$$
Divide by $2$:
$$x=-3.$$
Check: $2(-3)+9=-6+9=3$.

**13.** $7-3x=1$. Subtract $7$:
$$-3x=-6.$$
Divide by $-3$:
$$x=2.$$
Check: $7-3(2)=7-6=1$. A common error is to lose the minus and answer $x=-2$; the check catches it.

**14.** $\frac{x}{3}+5=2$. Subtract $5$:
$$\dfrac{x}{3}=-3.$$
Multiply by $3$:
$$x=-9.$$
Check: $\frac{-9}{3}+5=-3+5=2$.

**15.** $4(x-2)=20$. Divide both sides by $4$:
$$x-2=5.$$
Add $2$:
$$x=7.$$
Check: $4(7-2)=4\cdot5=20$. The alternative — distribute first to get $4x-8=20$, then $4x=28$, then $x=7$ — gives the same result and is equally valid.

**16.** $-2(x+3)=10$. Divide both sides by $-2$:
$$x+3=-5.$$
Subtract $3$:
$$x=-8.$$
Check: $-2(-8+3)=-2(-5)=10$.

**17.** $5x-3=2x+9$. Subtract $2x$ from both sides:
$$3x-3=9.$$
Add $3$:
$$3x=12.$$
Divide by $3$:
$$x=4.$$
Check: left $5(4)-3=17$; right $2(4)+9=17$.

**18.** $3x+8=5x-2$. Subtract $3x$ from both sides:
$$8=2x-2.$$
Add $2$:
$$10=2x.$$
Divide by $2$:
$$x=5.$$
Check: left $3(5)+8=23$; right $5(5)-2=23$.

**19.** $2(x+1)=3x-4$. Distribute:
$$2x+2=3x-4.$$
Subtract $2x$:
$$2=x-4.$$
Add $4$:
$$6=x.$$
Check: left $2(6+1)=14$; right $3(6)-4=14$.

**20.** $\frac{x}{2}+\frac{x}{3}=10$. The least common denominator is $6$; multiply every term by $6$:
$$3x+2x=60.$$
Collect:
$$5x=60.$$
Divide by $5$:
$$x=12.$$
Check: $12/2+12/3=6+4=10$.

**21.** $0.4x-1.2=0.2$. Add $1.2$:
$$0.4x=1.4.$$
Divide by $0.4$ (equivalently, multiply by $\frac{10}{4}$):
$$x=\dfrac{1.4}{0.4}=\dfrac{14}{4}=3.5.$$
Check: $0.4(3.5)-1.2=1.4-1.2=0.2$.

## Advanced

**22.** $\frac23x-\frac12=\frac16$. Add $\frac12$:
$$\dfrac23x=\dfrac16+\dfrac12=\dfrac16+\dfrac36=\dfrac46=\dfrac23.$$
Multiply both sides by the reciprocal $\frac32$:
$$x=\dfrac32\cdot\dfrac23=1.$$
Check: $\frac23(1)-\frac12=\frac46-\frac36=\frac16$.

**23.** $\frac{x-1}{2}=\frac{x+3}{5}$. Multiply both sides by the lcm $10$:
$$5(x-1)=2(x+3).$$
Distribute:
$$5x-5=2x+6.$$
Subtract $2x$:
$$3x-5=6.$$
Add $5$:
$$3x=11.$$
Divide by $3$:
$$x=\dfrac{11}{3}.$$
Check: left $\frac{\frac{11}{3}-1}{2}=\frac{\frac{8}{3}}{2}=\frac43$; right $\frac{\frac{11}{3}+3}{5}=\frac{\frac{20}{3}}{5}=\frac43$. The solution need not be an integer.

**24.** $0.08x+0.12(300-x)=30$. Multiply every term by $100$:
$$8x+12(300-x)=3000.$$
Distribute:
$$8x+3600-12x=3000.$$
Collect:
$$-4x+3600=3000.$$
Subtract $3600$:
$$-4x=-600.$$
Divide by $-4$:
$$x=150.$$
Check: $0.08(150)+0.12(150)=12+18=30$, since $300-150=150$.

**25.** $3(2x-1)-2(x+4)=5x-11$. Distribute both products:
$$6x-3-2x-8=5x-11.$$
Collect on the left:
$$4x-11=5x-11.$$
Add $11$:
$$4x=5x.$$
Subtract $4x$:
$$0=x.$$
Check: left $3(-1)-2(4)=-3-8=-11$; right $5(0)-11=-11$. Solution set $\{0\}$. Note that the solution is zero, which is not the same as having no solution.

**26.** $P=2(l+w)$. Divide both sides by $2$:
$$\dfrac{P}{2}=l+w.$$
Subtract $l$:
$$w=\dfrac{P}{2}-l.$$
Equivalently,
$$w=\dfrac{P-2l}{2}.$$
Check by substitution: $2\left(l+\left(\frac P2-l\right)\right)=2\cdot\frac P2=P$.

**27.** Let the three consecutive even integers be
$$n,\quad n+2,\quad n+4.$$
Their sum is $84$:
$$n+(n+2)+(n+4)=84.$$
Collect:
$$3n+6=84.$$
Subtract $6$:
$$3n=78.$$
Divide by $3$:
$$n=26.$$
The integers are $26,28,30$. Check: $26+28+30=84$. They are even and consecutive in the even-integer sense (differ by $2$).

**28.** Let the width be $w$ cm. The length is $2w+3$ cm. The perimeter condition gives
$$2w+2(2w+3)=54.$$
Distribute:
$$2w+4w+6=54.$$
Collect:
$$6w+6=54.$$
Subtract $6$:
$$6w=48.$$
Divide by $6$:
$$w=8.$$
The width is $8$ cm and the length is $2(8)+3=19$ cm. Check: $2(8)+2(19)=16+38=54$. Both dimensions are positive, so the answer is meaningful.

## Challenge

**29.** (a) $3(x+2)=3x+6$. Distribute the left side:
$$3x+6=3x+6.$$
Subtract $3x$:
$$6=6.$$
This is true for every real $x$. The equation is an identity, so it has **infinitely many solutions** (solution set $\mathbb{R}$).

(b) $2x+5=2x-1$. Subtract $2x$:
$$5=-1.$$
This is false for every $x$. The equation is a contradiction, so it has **no solution** (solution set $\varnothing$).

The two equations differ only after the variable cancels: a true constant statement means all values work, a false one means none does.

**30.** Start from
$$ax+b=cx+d.$$
Subtract $cx+b$ from both sides, which is legal by the addition property:
$$(a-c)x=d-b.$$

* If $a\neq c$, then $a-c\neq0$, so division by $a-c$ is legal by the multiplication property:
  $$x=\dfrac{d-b}{a-c}.$$
  There is exactly one solution.
* If $a=c$, the equation becomes $0=d-b$, that is, $b=d$. If $b=d$, the statement is true for every $x$ and there are infinitely many solutions. If $b\neq d$, the statement is false for every $x$ and there is no solution.

These cases are exhaustive: either $a\neq c$, or $a=c$ and $b=d$, or $a=c$ and $b\neq d$. Dividing by $a-c$ when $a=c$ would be division by zero, which is why the case must be separated.

**31.** Simplify the right side:
$$3(x+2)+x=3x+6+x=4x+6.$$
The equation becomes
$$4x+k=4x+6.$$
Subtract $4x$ from both sides:
$$k=6.$$

* If $k=6$, the statement is true for every $x$: infinitely many solutions.
* If $k\neq6$, the statement is false for every $x$: no solution.
* The equation can never have exactly one solution, because the coefficient of $x$ is $4$ on both sides for every value of $k$. The variable always cancels.

**32.** Let the capacity be $C$ litres. Initially the tank holds $\frac13C$ litres. After adding $8$ litres it holds $\frac34C$ litres, so
$$\dfrac13C+8=\dfrac34C.$$
Multiply every term by the lcm $12$:
$$4C+96=9C.$$
Subtract $4C$:
$$96=5C.$$
Divide by $5$:
$$C=\dfrac{96}{5}=19.2.$$
The capacity is $19.2$ litres. Check: initially $\frac13(19.2)=6.4$ litres; adding $8$ gives $14.4$ litres; and $\frac34(19.2)=14.4$ litres. The answer is positive, as a capacity must be.
