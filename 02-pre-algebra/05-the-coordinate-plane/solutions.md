# The Coordinate Plane — Solutions

> [Tutorial](README.md) · [Exercises](exercises.md)

Graphing solutions state the features used to draw the line: intercepts, slope and one or two check points. Distance and midpoint solutions show the substitutions, not only the final number.

## Beginner

**1.** The signs determine the quadrant:

* $(3,-5)$: $x>0$, $y<0$ — quadrant IV.
* $(-2,4)$: $x<0$, $y>0$ — quadrant II.
* $(-3,-1)$: $x<0$, $y<0$ — quadrant III.
* $(4,6)$: $x>0$, $y>0$ — quadrant I.

**2.** The point $(0,-3)$ has $x=0$, so it lies on the $y$-axis, $3$ units below the origin. Points on an axis are not assigned to any quadrant.

**3.** Right $3$ means $x=3$; down $2$ means $y=-2$. The point is $(3,-2)$, in quadrant IV.

**4.** Both points have $x=2$, so the segment is vertical:
$$d=|7-1|=6.$$
Equivalently, $\sqrt{(2-2)^2+(7-1)^2}=\sqrt{36}=6$.

**5.** Both points have $y=3$, so the segment is horizontal:
$$d=|4-(-1)|=5.$$

**6.**
$$d=\sqrt{(3-0)^2+(4-0)^2}=\sqrt{9+16}=\sqrt{25}=5.$$
This is the $3$–$4$–$5$ right triangle.

**7.**
$$M=\left(\dfrac{2+8}{2},\dfrac{4+10}{2}\right)=(5,7).$$

**8.**
$$M=\left(\dfrac{-3+1}{2},\dfrac{5+(-1)}{2}\right)=\left(\dfrac{-2}{2},\dfrac{4}{2}\right)=(-1,2).$$

**9.**
$$m=\dfrac{8-2}{3-1}=\dfrac{6}{2}=3.$$
The line rises $3$ units for every $1$ unit to the right.

**10.**
$$m=\dfrac{-3-5}{2-(-2)}=\dfrac{-8}{4}=-2.$$
The line falls $2$ units for every $1$ unit to the right.

**11.** Substitute $x=3$:
$$y=2(3)+1=7.$$
The $y$-intercept is the value when $x=0$: $y=1$, so the point is $(0,1)$.

## Intermediate

**12.** For the horizontal line, both $y$-coordinates are $5$:
$$m=\dfrac{5-5}{7-2}=0.$$
For the vertical line, both $x$-coordinates are $3$:
$$m=\dfrac{9-2}{3-3}=\dfrac{7}{0},$$
which is undefined. A vertical line has no slope; it is not a slope of zero.

**13.**
$$\Delta x=4-(-2)=6,\qquad \Delta y=5-(-3)=8,$$
$$d=\sqrt{6^2+8^2}=\sqrt{36+64}=\sqrt{100}=10.$$

**14.** Midpoint:
$$M=\left(\dfrac{-4+2}{2},\dfrac{1+9}{2}\right)=(-1,5).$$
Length:
$$\Delta x=2-(-4)=6,\qquad \Delta y=9-1=8,$$
$$d=\sqrt{6^2+8^2}=10.$$

**15.** The equation $y=-\frac12x+3$ is in slope-intercept form, so the slope is $-\frac12$ and the $y$-intercept is $(0,3)$.

For the $x$-intercept set $y=0$:
$$0=-\dfrac12x+3\implies \dfrac12x=3\implies x=6.$$
The $x$-intercept is $(6,0)$.

**16.** Solve for $y$:
$$3x+2y=12\implies 2y=-3x+12\implies y=-\dfrac32x+6.$$
The slope is $-\frac32$ and the $y$-intercept is $(0,6)$.

**17.** Slope-intercept form with $m=3$ and $b=2$:
$$y=3x+2.$$

**18.** First compute the slope:
$$m=\dfrac{7-1}{4-2}=\dfrac{6}{2}=3.$$
Use point-slope form with $(2,1)$:
$$y-1=3(x-2)\implies y-1=3x-6\implies y=3x-5.$$
Check $(4,7)$: $3(4)-5=7$.

**19.** For the $x$-intercept set $y=0$:
$$4x-0=8\implies x=2\implies (2,0).$$
For the $y$-intercept set $x=0$:
$$0-2y=8\implies y=-4\implies (0,-4).$$

**20.** Substitute $x=3$ into the right side:
$$2(3)-1=6-1=5,$$
which equals the $y$-coordinate $5$. Yes, the point is on the line.

**21.** Substitute each input:
$$f(0)=5(0)-3=-3,$$
$$f(-2)=5(-2)-3=-10-3=-13,$$
$$f\left(\dfrac12\right)=5\left(\dfrac12\right)-3=\dfrac52-\dfrac62=-\dfrac12.$$

## Advanced

**22.** The given line has slope $2$. A perpendicular line has slope
$$m=-\dfrac{1}{2}$$
because $2\cdot\left(-\frac12\right)=-1$. Through $(1,2)$:
$$y-2=-\dfrac12(x-1)\implies y=-\dfrac12x+\dfrac12+2=-\dfrac12x+\dfrac52.$$
The line is $y=-\frac12x+\frac52$.

**23.** The $y$-intercept is $(0,4)$, so $b=4$. Using $(1,7)$:
$$m=\dfrac{7-4}{1-0}=3.$$
Hence
$$y=3x+4.$$
Check $(2,10)$: $3(2)+4=10$. At $x=10$:
$$y=3(10)+4=34.$$

**24.** The slope is $8$: each additional hour costs \$8, so the units are dollars per hour. The $y$-intercept is $25$: the fixed charge when $n=0$, in dollars.

Set $C(n)=81$:
$$25+8n=81\implies 8n=56\implies n=7.$$
Seven hours cost \$81.

**25.**
$$\Delta x=5-(-3)=8,\qquad \Delta y=-2-4=-6,$$
$$d=\sqrt{8^2+(-6)^2}=\sqrt{64+36}=\sqrt{100}=10.$$

**26.**
$$M=\left(\dfrac{\dfrac12+\dfrac52}{2},\dfrac{-3+7}{2}\right)=\left(\dfrac{3}{2},2\right).$$
In decimal form this is $(1.5,2)$.

**27.** The distance condition is
$$\sqrt{(4-1)^2+(k-1)^2}=5.$$
Square both sides:
$$9+(k-1)^2=25\implies (k-1)^2=16.$$
Hence
$$k-1=4\quad\text{or}\quad k-1=-4,$$
so $k=5$ or $k=-3$. Both points $(4,5)$ and $(4,-3)$ are $5$ units from $(1,1)$; a circle of radius $5$ meets the vertical line $x=4$ twice.

**28.** The relation is **not** a function: the input $x=1$ is paired with both $y=2$ and $y=5$. A function must assign exactly one output to each input. Graphically, the vertical line $x=1$ would meet both points, violating the vertical line test.

For $f(x)=3x+1$, solve
$$3x+1=16\implies 3x=15\implies x=5.$$
Indeed $f(5)=16$.

## Challenge

**29.** Compute the slopes of the four sides:
$$m_{AB}=\dfrac{0-0}{4-0}=0,$$
$$m_{BC}=\dfrac{3-0}{5-4}=3,$$
$$m_{CD}=\dfrac{3-3}{1-5}=0,$$
$$m_{DA}=\dfrac{3-0}{1-0}=3.$$
Since $m_{AB}=m_{CD}=0$, sides $AB$ and $CD$ are parallel. Since $m_{BC}=m_{DA}=3$, sides $BC$ and $DA$ are parallel. A quadrilateral with both pairs of opposite sides parallel is a parallelogram.

Diagonals:
$$M_{AC}=\left(\dfrac{0+5}{2},\dfrac{0+3}{2}\right)=(2.5,1.5),$$
$$M_{BD}=\left(\dfrac{4+1}{2},\dfrac{0+3}{2}\right)=(2.5,1.5).$$
The diagonals have the same midpoint, so each diagonal bisects the other — a property of every parallelogram.

Is it a rectangle? Adjacent sides $AB$ and $BC$ have slopes $0$ and $3$, whose product is $0\neq-1$, so they are not perpendicular. (Equivalently, $AB$ is horizontal and $BC$ is not vertical.) Therefore $ABCD$ is a parallelogram but not a rectangle.

**30.** A point on $y=2x$ has the form $(x,2x)$. Its distance from the origin is
$$\sqrt{x^2+(2x)^2}=\sqrt{5x^2}=|x|\sqrt5.$$
Set this equal to $5$:
$$|x|\sqrt5=5\implies |x|=\dfrac{5}{\sqrt5}=\sqrt5.$$
Therefore $x=\sqrt5$ or $x=-\sqrt5$, giving the points
$$(\sqrt5,\,2\sqrt5)\quad\text{and}\quad(-\sqrt5,\,-2\sqrt5).$$
Check the first: $(\sqrt5)^2+(2\sqrt5)^2=5+20=25$, whose square root is $5$. The two points are symmetric about the origin, as expected on a line through the origin.

**31.** For each time interval, the slope is $\frac{\text{change in distance}}{\text{change in time}}$.

* From $0$ to $1$ hour: distance changes from $0$ to $12$, so the slope is $12/1=12$ km/h. The runner moves away from home at $12$ km/h.
* From $1$ to $2$ hours: distance stays at $12$, so the slope is $0/1=0$ km/h. The runner is stationary.
* From $2$ to $4$ hours: distance changes from $12$ to $20$, so the slope is $8/2=4$ km/h. The runner continues away at $4$ km/h.

Average speed is total distance divided by total time:
$$\dfrac{20\text{ km}}{4\text{ h}}=5\text{ km/h}.$$
It is *not* the average of $12$, $0$ and $4$ (which would be $\frac{16}{3}\approx5.33$); each speed applies for a different length of time, and the average of the speeds ignores that.

**32.** Compute the slopes:
$$m_{AB}=\dfrac{5-1}{3-(-1)}=\dfrac{4}{4}=1,$$
$$m_{BC}=\dfrac{9-5}{7-3}=\dfrac{4}{4}=1.$$
The segments $AB$ and $BC$ have the same slope and share the point $B$, so they lie on the same straight line; hence $A$, $B$ and $C$ are collinear.

Using point-slope form through $A(-1,1)$:
$$y-1=1\bigl(x-(-1)\bigr)=x+1\implies y=x+2.$$
Check all three points: $1=-1+2$, $5=3+2$, $9=7+2$. The line is $y=x+2$.
